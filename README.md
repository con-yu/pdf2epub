# PDF → EPUB 转换器

一个本地运行的网页工具，将 PDF 文件高质量转换为 EPUB 电子书。优先保证产出物质量：支持多级目录跳转、排版检查报告、页眉页脚清理；界面简洁美观，转换参数均可配置。

## 功能特性

### 产出质量
- **目录跳转**：优先使用 PDF 内嵌书签生成多级嵌套目录（EPUB NCX + Nav 双导航，兼容各类阅读器）
- **章节识别**：无书签的 PDF 按"字号阈值 + 粗体 + `第X章`/`Chapter N` 模式"自动识别章节标题
- **排版检查**：转换前可生成分析报告，展示章节树（层级/字数/图片数）、目录来源、正文字号，并对以下问题给出警告：
  - 扫描件 PDF（无文本层，需 OCR）
  - 未识别出任何章节标题
  - 内容为空或字数过少的可疑章节
- **排版清理**：自动剔除跨页重复的页眉、页脚与页码；去除与目录重复的标题行；断行智能合并为段落（中文无空格拼接，拉丁文补空格）
- **其他**：自动渲染首页为封面、提取正文图片并去重嵌入、自动识别书名/作者与中英文语言

### 网页工具
- 三步流程：拖拽上传 → 参数配置 → 分析报告 → 转换下载
- 全部本地运行，文件不上传到任何服务器

## 可配置参数

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| 书名 / 作者 | 留空则从 PDF 元数据或文件名自动识别 | 自动 |
| 优先使用 PDF 书签目录 | 使用内嵌书签作为章节结构 | 开 |
| 识别"第X章"模式标题 | 无书签时按常见章节命名模式识别 | 开 |
| 标题字号阈值 | 字号 ≥ 正文字号 × 该系数时判定为标题（1.05–1.6） | 1.15 |
| 去除页眉页脚与页码 | 清理跨页重复的边缘文本 | 开 |
| 提取正文图片 | 嵌入正文中的插图（按内容去重） | 开 |
| 正文字体 | 衬线（宋体系）/ 无衬线（黑体系）/ 楷体 | 衬线 |
| 行距 | 1.2–2.6 | 1.8 |
| 段首缩进 | 段落首行缩进两字符 | 开 |

## 快速开始

```powershell
cd d:\code\AI\pdf2epub
pip install -r requirements.txt
python app.py
```

然后访问 <http://127.0.0.1:5057/>。

**建议流程**：上传 PDF 后先点击「分析排版」，根据章节树和警告调整参数（如降低标题字号阈值以识别更多章节），再点击「转换并下载 EPUB」。

## 项目结构

```
pdf2epub/
├── app.py                  # Flask 服务入口（/api/analyze、/api/convert）
├── converter/
│   ├── pdf_parser.py       # PDF 解析：章节识别、页眉页脚剔除、图片提取、排版报告
│   └── epub_builder.py     # EPUB 生成：嵌套目录、可配置样式、封面、图片嵌入
├── templates/index.html    # 网页界面
├── static/
│   ├── style.css
│   └── app.js
├── tests/
│   └── test_e2e.py         # 端到端测试（生成测试 PDF 并校验 EPUB 结构）
└── requirements.txt
```

## 技术栈

- 后端：Python 3 + Flask
- PDF 解析：[PyMuPDF](https://pymupdf.readthedocs.io/)
- EPUB 生成：[ebooklib](https://github.com/aerkalov/ebooklib)

## 测试

```powershell
python tests\test_e2e.py
```

测试覆盖：页眉页脚/页码剔除、重复标题行清理、嵌套目录跳转链接、封面与样式表生成、EPUB 结构完整性。样例输出保存为 `tests/output.epub`。

## 已知限制

- 扫描件 PDF 没有文本层，需要先经 OCR 处理才能转换
- 复杂多栏排版、图文混排的阅读顺序可能与原文有差异
- 超大文件（几百页以上）转换需要几秒到几十秒，请耐心等待
